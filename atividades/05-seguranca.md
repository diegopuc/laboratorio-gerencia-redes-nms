# 05 — Segurança e monitoramento passivo
Teste `docker compose exec servidor1 curl http://firewall:8080`. Bloqueie o serviço com `docker compose exec firewall iptables -I INPUT -p tcp --dport 8080 -j REJECT`. Repita o teste e a consulta SNMP. Gere um evento didático com `docker compose exec firewall sh -c 'logger -n syslog -P 514 -t laboratorio "Bloqueio HTTP simulado"'`. Verifique o syslog do NMS (habilite a função Syslog se necessário). A mensagem é simulada, não captura automática do iptables. Remova a regra com `docker compose exec firewall iptables -D INPUT -p tcp --dport 8080 -j REJECT`. Diferencie polling e mensagens espontâneas.
